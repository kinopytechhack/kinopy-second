# Kinopy's Second (PWA / Mobile Web App)

iPhoneや各種ブラウザからいつでもアクセスできる「Kinopy's Second」のPWA（Progressive Web App）クライアントです。

- **本番URL**: https://kinopytechhack.github.io/kinopy-second/
- **GitHubリポジトリ**: https://github.com/kinopytechhack/kinopy-second

## 同期（gas-second-sync）の動き（2026-09-30 Step3.5）
- 会話・メモの書き込みは「未送信キュー」（localStorage `companion_outbox`）に入れてから送る。短いものはGET（fetch→だめならJSONP）、URLに収まらない長文だけPOST。書き込みは応答を25〜30秒まで待つ（ロック待ち＋Driveの読み書きで6秒を超えるため）。サーバーが `success:true` を返したときだけキューから消す。各書き込みに `clientId` を付け、再送しても1回だけ書かれる
- 「未同期」は書き込みが送れないときだけ出す（読み取りの失敗では出さない）。送信中は「送信中…」
- 合言葉違い（`code:UNAUTHORIZED`）・通信失敗は、設定画面の同期欄とチャット画面下の表示に「未同期」と出る。未送信分は起動時・同期時・オンライン復帰時・表示のタップで再送
- メモのアーカイブ・削除はサーバーにも送る（`updateMemo`／`deleteMemo`）。削除が送信待ちの間は同期で復活させない（判定は未送信キューのみ）。他の端末で消されたメモは、この端末からも消す
- 同期の合言葉は設定画面で入力し、その端末（開く場所）だけに保存する（`companion_sync_token`）。空欄のときはコード内の既定値を使う（既定値の削除と値の入れ替えはステップ4-3）

## Kumapy との連携（2026-09-30 ステップ4-2）
- Kumapy の合言葉は **Second 同期の合言葉とは別の値**。設定画面の「Kumapy WebApp URL」の下の欄に入力し、その端末（開く場所）だけに保存する（`kumapy_access_key`）。コード・README には書かない
- 表示はスプレッドシートから取る（Kumapy の `api_getTasks` は返事に30秒以上かかることがあり、30秒ごとの表示には使えない。前の版も6秒で打ち切っていて実際はスプレッドシート表示だった）。Kumapy との接続と合言葉は、起動時・5分ごと・設定の保存時に doPost（`{token, action:'ping'}`、45秒まで待つ）で確かめる。URL に合言葉を載せない。旧版が保存していた URL の `key=`／`k=` は読み込み時に取り除く
- 設定画面の欄の右に「つながっています／合言葉が未入力／違います／届きません」を出す（どの場合も表示はスプレッドシート。スプレッドシートの直接読み取りの扱いはステップ4-3）
- 「Kumapy を開く」は合言葉を付けずにブラウザで開く。開いた先の Kumapy の画面で1回入力する

## 合言葉とデータの取り方（2026-09-30 ステップ4-3）
- **このリポジトリと GitHub Pages は公開されている。** コード・README に合言葉・個人情報を書かない（公開JSは誰でも読める）
- 同期の合言葉は**必須**（コード内の既定値は廃止）。未入力の間は同期サーバーに何も送らず、「未同期（合言葉が未入力）」と表示し、発言・メモは未送信キューに残す。入力して保存すると `checkToken` で確かめ、通れば未送信分を送る
- Kumapy のタスク表示は、スプレッドシートの CSV 直接読み取りをやめ、同期サーバーの `getKumapyTasks`（60秒ごと。サーバーで20秒キャッシュ）から取る。天気・睡眠は `getDailyContext` のみ（CSV の予備経路は削除）。設定の「Kumapy スプレッドシート URL / ID」「天気・睡眠シートID」の欄は削除
- システムプロンプトは、公開JSにはマットのキャラクター部分だけを置き、プロフィール入りの全文は Vault（`70_Second/Matt_Stiller_SystemPrompt.md`）から同期サーバーの `getPersona` で受け取って端末に保存する（`companion_persona_prompt`。1日1回と合言葉の保存時に更新）
- PWA を変えたら `index.html` の `app.js?v=`・`style.css?v=` を必ず上げる
